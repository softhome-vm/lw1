# lw1 — Основы PHP (условия и ввод)

Консольные скрипты на PHP: ввод через `readline`, ветвления `if` / `elseif` / `switch`.

## Задания

| Файл | Тема |
|------|------|
| `task1V2.php` | Проверка числа на палиндром |
| `task2V2.php` | Скидка от суммы покупки (ступенчатые пороги) |
| `task3V2.php` | Положение точки на координатной плоскости (оси, квадранты) |

## Запуск

```bash
php task1V2.php
```
